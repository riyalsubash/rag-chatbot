# RAG Chatbot with Claude AI & Local Embeddings

This repository contains the code for a full-stack RAG (Retrieval-Augmented Generation) chatbot. It allows users to upload their documents (PDF, Excel, CSV, TXT) and ask questions, receiving answers generated by Anthropic's Claude 3.5 Sonnet model based on the provided context.

A key feature of this project is its use of **free, local embeddings** (using Sentence Transformers), which eliminates API costs for vectorization and enhances privacy.

![Chatbot Interface](screenshot.png) ## Features

* **Multi-Format Document Support:** Upload and process `.pdf`, `.xlsx`, `.xls`, `.csv`, and `.txt` files.
* **High-End AI Model:** Utilizes **Anthropic's AI** for state-of-the-art reasoning and answer generation.
* **Cost-Free Embeddings:** Generates text embeddings locally using a Sentence Transformer model, avoiding API fees from providers like OpenAI or Cohere.
* **Context-Aware Chat:** Maintains conversation history to answer follow-up questions.
* **Source Citations:** (Feature from UI) Provides citations for answers based on the uploaded documents.
* **Responsive UI:** Clean and simple web interface built with HTML, CSS, and vanilla JavaScript.

## Tech Stack

* **Backend:** Python (Flask)
* **Frontend:** HTML, CSS, JavaScript
* **LLM:** Anthropic Claude AI
* **Embeddings:** Sentence Transformers (e.g., `all-MiniLM-L6-v2`)
* **Vector Store:** FAISS (or other local vector DB like ChromaDB/LanceDB)
* **Document Processing:** LangChain (or LlamaIndex) for document loading and text splitting.

## How It Works (Architecture)

1.  **File Upload:** The user uploads one or more documents via the web interface.
2.  **Processing:** The Flask backend receives the files.
3.  **Load & Chunk:** `langchain` document loaders read the text from the files. The text is then split into smaller, manageable chunks.
4.  **Embed & Store:** A local Sentence Transformer model computes vector embeddings for each chunk. These embeddings are stored in a local FAISS vector store for efficient retrieval.
5.  **User Query:** The user submits a question through the chat interface.
6.  **Retrieve:** The user's question is embedded. A similarity search is performed against the FAISS index to find the most relevant document chunks (the "context").
7.  **Generate:** The original question, chat history, and the retrieved context are passed in a prompt to the Claude AI API.
8.  **Response:** The AI-generated answer is streamed back to the user interface.

## Installation and Setup

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/riyalsubash/rag-chatbot.git
    cd rag-chatbot
    ```

2.  **Create a Virtual Environment:**
    ```bash
    # For Linux/macOS
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set Up Environment Variables:**
    Create a `.env` file in the root directory and add your Anthropic API key:
    ```
    CLAUDE_KEY=your_claude_api_key_here
    ```

5.  **Run the Application:**
    ```bash
    python app.py
    ```

6.  **Access the Chatbot:**
    Open your web browser and navigate to `http://127.0.0.1:5000` (or the port specified by Flask).
